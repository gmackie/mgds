P2 result lane

No passing campaign result is present until immutable inputs, all 90 signed evaluator run records, host conformance, required soak duration, signatures, and byte-level replay are recorded. Missing and failed runs remain explicit.

runs.json is the append-only campaign input. evidence.json maps signed content hashes to tracked, repository-relative evidence bundle files; the gate applies size limits before reading, validates schemas and privacy classification, verifies bundle bytes, replays event ledgers, re-hashes embedded artifact bytes, and requires every task-declared evidence role. host-t0.json names locally downloaded CI artifacts; the release gate derives their hashes and verifies their GitHub provenance against the exact release source digest rather than trusting declared URLs or verdicts. campaign.json is a published status snapshot only and is never accepted by the release gate in place of recomputation.
