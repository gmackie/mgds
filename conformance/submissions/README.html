Conformance submissions

Submit mgds.p3-bundle/v1 bytes plus the submitter public key. The signed manifest identifies adapter and protocol versions, immutable source revision, Unity toolchain, host, T0 report, representative task evidence, event-ledger head, evaluator identity, and public-redacted privacy classification.

Artifact paths must be portable and unique under case folding. Traversal, absolute paths, private identities, credentials, unhashed evidence, unbounded files, invalid signatures, or a non-pass T0/T1 result fail closed.

Build with pnpm p3:build and replay independently with pnpm p3:replay. See the P3 protocol for the exact ceremony and acceptance boundary.
