Result reproduction

Verify sealed task and evaluator identities, replay the event hash chain, hash every artifact byte, verify the Ed25519 attestation, then compare authoritative assertions. Agent narrative and agent-authored verdicts are non-authoritative.

P2 campaign

pnpm campaign:plan
# Place the array of harness run records at artifacts/campaigns/p2-runs.json
pnpm campaign:evaluate
pnpm release:p2:check

The plan is derived from repository bytes and contains the exact 90-slot P2 Cartesian matrix. Evaluation rejects unexpected or duplicate slots, substituted task, budget, environment, model, harness, host, seed, or repetition provenance, private harness affordances, malformed provenance, unsigned evaluator verdicts, non-repeatable seeds, missing 240-minute host/harness soak coverage, orphan processes, and unknown workspace state. A missing slot is reported as incomplete rather than silently excluded.

Each run names a content hash in results/p2/evidence.json. The evaluator bounds file and campaign size before reading, checks every runtime document against the normative schemas, checks the raw bundle hash, applies the publication privacy contract, replays the event hash chain, and decodes and re-hashes every embedded artifact. The exact task-declared compile, tests, event-ledger, screenshot, and player-build roles are mandatory. A claimed replay status is never sufficient on its own.

The P2 release check is expected to exit non-zero while external evidence is pending. Host artifacts are checked with gh attestation verify against the exact repository, conformance workflow, refs/heads/main, and release source digest; URL strings are not evidence. Review approval must sign the content hash of the actual report with an externally pinned reviewer key.

Set MGDS_TRUSTED_EVALUATOR_FINGERPRINTS and MGDS_TRUSTED_REVIEWER_FINGERPRINTS to JSON maps, MGDS_RELEASE_AUTHORITY_FINGERPRINT to the out-of-band SHA-256 fingerprint, and MGDS_RELEASE_SOURCE_DIGEST to the exact Git commit SHA. Run the gate from a clean checkout of that commit; every release input and evidence bundle must be tracked there. The independent reviewer signs a target hash covering the candidate, source, campaign, host evidence, and evaluator trust. The final Ed25519 signature then covers one release-subject hash binding all of those inputs plus the exact review report and reviewer trust.

Review and signing are intentionally detached from the source commit. Place review.json, review.html, reviewer-authorities.json, release-authorities.json, and signing.json in artifacts/release/p2/. Once the source, campaign, host evidence, and evaluator trust inputs are complete, the blocked gate output publishes the stable reviewTargetHash; after review approval is present, it publishes the final releaseSubjectHash for signing. Because artifacts/ is ignored, neither action changes the approved source digest.
