MGDS Quickstart

  1. Install the pinned Node, pnpm, Python, .NET, and Unity versions.
  2. Run pnpm install --frozen-lockfile and pnpm check.
  3. Run mgds doctor, then mgds discover.
  4. Execute the sealed key-exit sample task with its declared policy and budget.
  5. Replay the emitted content hashes and evaluator attestation independently.

No account or private adapter affordance is required for the public reference lane.
