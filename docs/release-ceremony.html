P2 review and release ceremony

  1. Freeze the exact candidate, clean source digest, 90 signed runs, evidence bundles, verified three-host provenance, and evaluator trust roots.
  2. Compute the review target with the release gate. An external reviewer writes a non-empty report and an unsigned approval containing exact report and target hashes.
  3. The reviewer signs with node scripts/sign-p2-review.mjs --review … --report … --private-key … --output …. Their private key must be owner-only and outside the repository; their public-key fingerprint is pinned out of band.
  4. Recompute the gate and release subject. The independent release authority signs only that exact subject using node scripts/sign-p2-release.mjs --subject … --private-key … --output ….
  5. Run pnpm release:p2:check. Publish only when the result is ready with no blockers.

Tooling does not confer independence. Repository maintainers must not impersonate the reviewer or release authority, and pending external acts remain explicit blockers.
