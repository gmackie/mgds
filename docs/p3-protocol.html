P3 clean-room adapter protocol

  1. An unaffiliated team receives only public tagged specifications, SDKs, fixtures, and conformance tools.
  2. Private schemas, implementation guidance, and GMacko source are prohibited.
  3. The team records questions as public specification issues.
  4. Its adapter must pass T0 and representative T1 tasks.
  5. It submits sealed inputs, environment provenance, event ledger, artifacts, evaluator output, and attestation for independent replay.

P3 completes only when this external evidence is accepted.
